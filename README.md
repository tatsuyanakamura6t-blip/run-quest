# Run Quest

ランニングの距離・時間・ペースを計測し、走った軌跡を地図に描くWebアプリ（プロトタイプ）。

## 動かし方

位置情報を使うため、HTTPS か `localhost` で開く必要があります。

```sh
cd run-quest
python3 -m http.server 8000
```

ブラウザで http://localhost:8000 を開きます。
室内で試すときは、画面下の「シミュレーション」にチェックを入れると自動で走ってくれます（×10 / ×30 で早送り）。

## ファイル構成

| ファイル | 内容 |
| --- | --- |
| `index.html` | 画面の部品（地図・計測値・ボタン） |
| `style.css` | 見た目（色・レイアウト） |
| `app.js` | 動きのすべて（GPS・計測・軌跡の描画など） |

## app.js の中身（どこに何があるか）

`app.js` は `// ===== 見出し =====` のコメントで区切ってあります。エディタで見出し名を検索すると飛べます。

| 見出し | 役割 |
| --- | --- |
| 設定 | GPSの精度のしきい値・平滑化の強さなど、調整用の数値 |
| 地図 | Leaflet の地図・現在地マーカー |
| ランの状態 | 距離・時間・記録した点などの変数 |
| 時計 | シミュレーション時に時間を早送りするための仕組み |
| 位置情報の入口 | GPSの位置を受け取り、平滑化して記録する（`onPosition` / `recordPoint`） |
| 軌跡の平滑化 | カルマンフィルタでGPSのブレを抑える／スプラインで線を曲線にする |
| 実機GPS | スマホのGPSから位置を取る |
| シミュレーション | 室内テスト用の仮想ラン |
| 操作 | スタート・一時停止・終了ボタンの処理 |
| 画面更新 | 距離・時間・ペースの表示 |
| 画面スリープ防止 | 計測中に画面が消えないようにする |
| ユーティリティ | 距離計算・時間やペースの表示形式 |

### よく調整する数値（「設定」の中）

| 名前 | 意味 |
| --- | --- |
| `MAX_ACCURACY_M` | これより精度が悪いGPS点は記録しない |
| `MIN_STEP_M` | これより小さい移動はブレとして無視 |
| `KALMAN_Q` | 軌跡の平滑化の強さ。小さいほどなめらか、大きいほど急な曲がり角に素早く反応 |
| `CURVE_STEP_M` | 曲線を描くときの細かさ（m） |

## 変更履歴

### 2026-11-08 軌跡をなめらかに

- **`app.js` › 軌跡の平滑化（新規）**
  - `createKalman`：GPSのブレを抑えるカルマンフィルタ。位置と速度を同時に推定するので、走っている人に遅れずについていく。テストでは位置の誤差が平均 約4m → 約2.5m に減った。
  - `smoothPath` / `catmullRom`：記録した点をすべて通るなめらかな曲線（Catmull-Rom スプライン）を作る。
- **`app.js` › 位置情報の入口**：`onPosition` でGPSの位置を平滑化してから使うように変更（マーカー・軌跡・距離すべてに反映）。`recordPoint` は線を曲線で描き直す `redrawCurrentLine` を呼ぶように変更。
- **`app.js` › 設定**：`KALMAN_Q`・`KALMAN_RESET_MS`・`CURVE_STEP_M` を追加。
- **`app.js` › 操作**：`beginSegment` で線の端と角を丸く描くように変更。
- **`README.md`**：新規作成。
